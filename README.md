# Comparative Performance Analysis of MobileNetV2 and VGG16 Based on Transfer Learning for Digital Waste Image Classification

## Overview
This repository contains the implementation and experimental results of a comparative study of MobileNetV2 and VGG16 using transfer learning for waste image classification.

## Dataset
The dataset is publicly available on Kaggle:

https://www.kaggle.com/datasets/auliarashad/dataset-klasifikasi-sampah

## Models
- MobileNetV2
- VGG16

## Experimental Setup
- Training, validation, and testing split: 70%, 20%, and 10%
- Random seed: 42
- Transfer learning and fine-tuning

## Repository Contents
- `revisi_paper_fixed.ipynb`: Training and evaluation notebook
- `confusion_matrix_comparison.png`: Confusion matrix results
- `training_history_comparison.png`: Training history
- `class_distribution_before_after.png`: Dataset distribution
- `comparison_table.csv`: Model comparison results

## How to Run
1. Download or open the notebook in Google Colab.
2. Download the dataset from Kaggle.
3. Configure the dataset path according to the notebook.
4. Run the notebook cells sequentially.

## Data and Code Availability
The dataset used in this study is publicly available on Kaggle. The training code and supporting experimental results are available in this repository.
